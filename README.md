## Core Patterns

- **Uneven U Explainer**: Eric Hayot's Uneven U: traverse Concept (Level 5) -> Claim (Level 4) -> Mechanism (Level 3) -> Data/Code (Level 1) -> Meaning (Level 4).
- **Practical Application**: System documentation, code walkthroughs, and complex algorithmic onboarding.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
